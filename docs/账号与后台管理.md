# 账号与后台管理

## 使用方式

- 登录地址：`http://localhost:5173/login`；管理员登录后侧栏显示“管理后台”。
- 账号支持普通名称、中文名称或公司邮箱，不再校验邮箱格式；名称去除首尾空格并忽略英文大小写。经用户明确授权，未登记账号输入 `123456` 后自动创建为普通用户并直接进入工作台；错误密码不创建账号。
- 初始密码为 `123456`。自动创建的普通账号不强制首次改密，可主动修改；管理员创建或重置密码的账号仍要求首次改密。已有账号使用当前密码，停用账号不会因登录而自动恢复。
- 管理后台提供用户总数、启用账号数、处理任务数、完成任务数和操作记录数。
- 用户管理支持按邮箱搜索、创建用户/管理员、设置账号类型、启停普通账号、重置密码、查看用户操作记录。
- 功能权限包含 CV 处理、JD 处理、JD 库、模板管理、术语库。账号类型是业务分类标签，实际授权以功能勾选项为准；管理员具有全部权限。
- “任务与文件”支持按用户 ID、状态筛选，查看任务详情，下载已归档 PPTX、DOCX、PDF（仅展示实际存在的格式）。普通用户历史页只显示本人记录。

## 首位管理员

需要项目负责人提供真实公司邮箱，不预置通用管理员账号；网页登录自动创建的账号不会获得管理员权限。可在服务器上执行：

```powershell
Set-Location C:\Users\IAV\Desktop\ai_resume\backend
$env:DEBUG='false'
..\tmp\python313\python.exe manage_users.py admin 真实邮箱@公司域名
```

创建后用此邮箱和 `123456` 登录，按页面提示改密。重复邮箱会被拒绝，不覆盖已有账号。后续账号可以直接在管理后台创建。

## 存储与审计

- 使用项目现有 `backend/data/resume_converter.db`，增量创建 `access_users`、`access_sessions`、`access_audit`、`access_resources` 表，不删除原表。
- 密码采用独立随机盐与 PBKDF2-SHA256（600000 次）保存；数据库不保存明文密码。
- 会话采用随机令牌、HttpOnly/SameSite=Strict Cookie，数据库只保存令牌 SHA256 摘要，8 小时到期。生产环境 `ENVIRONMENT=production` 启用 Secure Cookie，需要 HTTPS。
- 修改密码撤销其他设备会话；重置密码、停用账号撤销该用户全部会话。功能授权每次请求从数据库校验。
- 来自浏览器的写请求校验 Origin；新增访问域名需加入 `CORS_ORIGINS`。前端默认走 `/api/v1` 同源代理，生产反向代理也需转发此前缀。
- 同一来源 IP 在 15 分钟内发生 10 次登录失败后暂时限制登录；记录来源为直接连接 IP，不信任任意转发请求头。
- 记录所有 `/api/v1` 请求的用户、UTC 时间、HTTP 操作/路由、结果码、关联标识、来源 IP（含轮询和下载）；另外记录任务创建及状态变化。页面显示本地时间。
- 不记录密码、会话令牌、请求正文或简历正文。操作日志反映服务端接口行为，不记录鼠标移动、未提交文本等纯本地操作。下载记录表示服务端响应，不证明客户端已保存成功。
- 新任务记录上传者、原始文件名、状态、任务标识。完成文件复制到 `backend/output/archive/<task_id>/`，可以在服务重启后下载。
- 启用前的输出文件标记为“历史文件”，仅管理员可访问；无法追溯以前未记录的操作及文件创建人。系统不捏造历史归属。
- 进行中任务仍由现有内存执行器运行，重启后标记“服务重启中断”，不会伪装成继续执行；需要重新提交。归档文件和已有日志不受影响。
- 现有低层简历诊断接口限制为管理员使用，避免绕过任务所有权读取其他人的上传/输出。模板和 JD 库仍为组织共享资源，由对应功能权限控制。

## 实现位置及维护

| 范围 | 文件 |
| --- | --- |
| 账号、会话、审计、资源模型 | `backend/app/models/access.py` |
| 登录、改密、授权、后台接口 | `backend/app/api/access.py` |
| 密码散列、资源归属、文件归档 | `backend/app/services/access_service.py` |

| 个人历史及后台文件列表 | `frontend/src/components/AccountRecords.vue` |

| 权限和归档回归测试 | `backend/tests/test_access_control.py` |

新增功能权限时，同时增加后端权限白名单、接口校验、管理员勾选项与前端入口控制。不能只隐藏按钮。

备份时同时备份 SQLite 数据库、上传目录和输出归档目录。当前没有自动清理审计记录或文件的策略。

### 自动创建普通账号（用户明确授权后启用）

未登记账号使用 123456 登录时自动创建普通用户并直接进入；错误密码不创建账号。已有账号密码、停用状态和管理员权限不被覆盖。同名重复登录复用原账号，创建事件写入审计日志。

验证：自动注册、账号名称、访问控制共 14 项测试通过，前端构建通过；确认无活跃任务后重启后端，健康检查通过。
