## 📊 功能详解

### 1. 自动克隆表格行

**原理：** 使用XML底层操作克隆表格行，不需要修改模板。

**效果：**
- 模板只要1行 `{{work.company}}` 占位符
- 代码自动检测有3条工作经历
- 自动克隆2次 → 变成3行
- 每行填入对应的经历

### 2. 逐条填充

**工作原理：**
```
第1行 ← {{work.company}} ← work[0] (Company A)
第2行 ← {{work.company}} ← work[1] (Company B)  
第3行 ← {{work.company}} ← work[2] (Company C)
```

### 3. 自动调整行高

**原理：** 估算文本行数，动态设置行高。

**效果：**
- 内容短 → 行高小
- 内容长 → 行高自动变大
- 确保内容完整显示

### 4. 分页功能 (可扩展)

当前框架支持，如需完整功能可继续扩展：
- 检测页面内容高度
- 超出时自动创建新幻灯片
- 继续在新页面填充
