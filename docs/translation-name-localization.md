# 公司、学校和项目名称翻译规则

公司、学校（包含学院）及学位字段必须参与目标语言翻译。中文输出不再将这些字段中的英文作为专名直接放行。翻译入口、重试检查和最终审查共用字段策略；源数据的 language 即使已经是 CN，也不能跳过英文名称。

名称交给 LLM 处理：优先使用已知官方目标语言名称，其次采用通行译名；没有可靠译名时合理音译或意译，不编造法人全称、地区、隶属关系，也不宣称生成的译名经过官方核实。

项目名称单独检查：业务描述必须翻译；允许技术缩写、产品标识、工具名、协议名及型号保留，例如 DCA、PFO、QuickAccessKey。首字母大写的普通英文词不再使项目标题整体免于翻译。机构和学位字段使用更严格的规则，例如 MBA 也需要译为对应中文学位。

仍未翻译的字段进入既有补译流程，总计最多三次模型调用。达到上限后保留最近的非空结果，并由最终审查记录字段路径供人工复核；本次不改变继续输出草稿的既有行为。规则校验只能发现语言残留，不能证明名称译法准确。

## 后续术语库

本次不新增机构术语、不开发术语管理或自动学习功能，保留项目现有术语注入机制。后续对无通行译名、特殊拼写、必须保留外文的机构，考虑记录原名、目标语言、确认译名、上下文、来源及审核状态，并让经确认的例外同时用于提示词和残留校验。不得将模型生成的音译自动作为已核实术语入库。

## 验证

新增名称翻译回归测试覆盖截图中的公司、学校、学历、项目描述，以及未知机构、混合语言、原样返回后的补译、重试耗尽、源对象不被修改和英文目标兼容。测试使用模拟 LLM，未进行真实模型调用或重新导出截图对应简历。
