# PPT模板修改指导

## 问题分析

当前模板使用的是不带索引的占位符：
```
{{work.company}}
{{work.period}}
{{work.role}}
{{work.tasks}}
```

这种方式只会填充第一条工作经历。

## 解决方案

### 方案1：修改模板使用带索引的占位符（推荐）

在PPT模板中预留多行，每行使用不同的索引：

**工作经历部分：**
```
第1行:
  {{work0.company}}
  {{work0.period}}
  {{work0.role}}
  {{work0.tasks}}

第2行:
  {{work1.company}}
  {{work1.period}}
  {{work1.role}}
  {{work1.tasks}}

第3行:
  {{work2.company}}
  {{work2.period}}
  {{work2.role}}
  {{work2.tasks}}
```

**项目经历部分：**
```
第1行: {{project0.company}} | {{project0.period}} | {{project0.name}} | {{project0.role}}
第2行: {{project1.company}} | {{project1.period}} | {{project1.name}} | {{project1.role}}
```

**教育经历部分：**
```
第1行: {{education0.school}} | {{education0.period}} | {{education0.degree}} | {{education0.major}}
第2行: {{education1.school}} | {{education1.period}} | {{education1.degree}} | {{education1.major}}
```

### 方案2：使用我们的代码自动填充（需要模板预留行）

我们的代码已经支持：
- 如果模板中有带索引的占位符，自动对应填充
- 如果数据条数少于预留行数，清空多余行
- 如果数据条数多于预留行数，只填充有的行

## 具体修改步骤

### 1. 打开现有PPT模板

### 2. 找到工作经历区域

### 3. 复制粘贴现有的工作经历行，创建多行

例如：复制2次，得到3行

### 4. 修改每行的占位符，加上索引

**第一行（不变或加0）：**
```
{{work0.company}}
{{work0.period}}
{{work0.role}}
{{work0.tasks}}
```

**第二行（加1）：**
```
{{work1.company}}
{{work1.period}}
{{work1.role}}
{{work1.tasks}}
```

**第三行（加2）：**
```
{{work2.company}}
{{work2.period}}
{{work2.role}}
{{work2.tasks}}
```

### 5. 对项目经历和教育经历做同样处理

### 6. 保存模板

## 测试验证
