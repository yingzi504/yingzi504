# 翻译复核与人工修改

当前术语库尚未完善，语言残留检查仅用于辅助修复，不作为输出门禁。

- 每个字段或职责条目最多调用模型 3 次（初次翻译 + 最多 2 次修复）。
- 达到上限仍有残留时保留最后一次非空译文；所有结果均为空时保留原文，避免内容丢失。
- 修复调用发生服务错误时保留已有内容；初次调用发生真实服务错误仍按原有错误流程处理。任务取消继续传播。
- 工作/项目职责逐条翻译并保留顺序，外层不再重复修复，不会放大重试次数。
- 翻译后及摘要后的整份复核只进行日期标准化并记录待人工检查字段，不再调用模型，也不阻止生成 PPTX/PDF。
- 进度提示展示有限的修复轮数。达到上限会继续生成可供人工修改的文件。

回归覆盖持续残留、连续空结果、部分译文后空结果、修复服务异常、职责顺序、取消，以及残留存在时流水线仍完成并调用文件生成。
