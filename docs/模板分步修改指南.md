# PPT模板分步修改指南

## 当前问题

模板中只有单行占位符，导致只显示第一条工作经历。

## 解决方案：5步修改模板

### 第1步：打开模板文件

打开文件：
```
d:\ai_resume\backend\templates\New_Template_IAV_Resume_CN.pptx
```

### 第2步：修改工作经历部分（支持3条）

**找到工作经历表格区域，当前内容：**
```
{{work.period}} | {{work.company}}
{{work.role}}
Tasks:
{{work.tasks}}
```

**操作：**
1. 选中整个工作经历所在的表格行或文本框
2. 按 `Ctrl+C` 复制
3. 按 `Ctrl+V` 粘贴2次，得到3行
4. 修改每行的占位符：

**第1行修改为：**
```
{{work0.period}} | {{work0.company}}
{{work0.role}}
Tasks:
{{work0.tasks}}
```

**第2行修改为：**
```
{{work1.period}} | {{work1.company}}
{{work1.role}}
Tasks:
{{work1.tasks}}
```

**第3行修改为：**
```
{{work2.period}} | {{work2.company}}
{{work2.role}}
Tasks:
{{work2.tasks}}
```

### 第3步：修改项目经历部分（支持2条）

**找到项目经历区域，当前内容：**
```
{{project.period}} | {{project.company}}, {{project.role}}
{{project.name}}
Tasks:
{{project.tasks}}
```

**操作：**
1. 复制粘贴1次，得到2行
2. 修改占位符：

**第1行：**
```
{{project0.period}} | {{project0.company}}, {{project0.role}}
{{project0.name}}
Tasks:
{{project0.tasks}}
```

**第2行：**
```
{{project1.period}} | {{project1.company}}, {{project1.role}}
{{project1.name}}
Tasks:
{{project1.tasks}}
```

### 第4步：修改教育经历部分（支持2条）

**找到教育经历区域，当前内容：**
```
{{education.period}} | {{education.school}}
- {{education.degree}} of {{education.major}}
```

**操作：**
1. 复制粘贴1次，得到2行
2. 修改占位符：

**第1行：**
```
{{education0.period}} | {{education0.school}}
- {{education0.degree}} of {{education0.major}}
```

**第2行：**
```
{{education1.period}} | {{education1.school}}
- {{education1.degree}} of {{education1.major}}
```

### 第5步：保存模板

按 `Ctrl+S` 保存文件。

## 常见问题

**Q: 如果我的数据少于3条工作经历怎么办？**

A: 代码会自动清空多余的行，不用担心。

**Q: 如果我的数据多于3条怎么办？**

A: 只会显示前3条，可以在模板中继续添加第4、第5行...

**Q: 可以只修改工作经历，不修改其他吗？**

A: 可以，代码会兼容处理。
