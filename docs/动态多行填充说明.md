# 动态多行工作经历填充功能说明

## 功能概述

现在系统支持根据 `resume_data.work` 的实际数量动态填充多行工作经历、项目经历和教育经历。

## 支持的占位符格式

### 工作经历
- `{{work.company}}` - 第一条记录（向后兼容）
- `{{work0.company}}` - 第一条记录
- `{{work1.company}}` - 第二条记录
- `{{work2.company}}` - 第三条记录
- 以此类推...

其他工作经历字段：`period`, `role`, `tasks`

### 项目经历
- `{{project.name}}` - 第一条记录（向后兼容）
- `{{project0.name}}` - 第一条记录
- `{{project1.name}}` - 第二条记录
- 以此类推...

其他项目经历字段：`company`, `period`, `role`, `tasks`

### 教育经历
- `{{education.school}}` - 第一条记录（向后兼容）
- `{{education0.school}}` - 第一条记录
- `{{education1.school}}` - 第二条记录
- 以此类推...

其他教育经历字段：`period`, `degree`, `major`

## 使用方式

### 方式1：模板预留多行（推荐）

在PPT模板中提前预留多行，每行使用带索引的占位符：

```
第1行: {{work0.company}} | {{work0.period}} | {{work0.role}}
第2行: {{work1.company}} | {{work1.period}} | {{work1.role}}
第3行: {{work2.company}} | {{work2.period}} | {{work2.role}}
```

系统会根据实际数据条数自动填充：
- 有3条数据 → 填充3行
- 只有2条数据 → 填充2行，清空第3行

### 方式2：使用不带索引的占位符（向后兼容）

如果模板中只有不带索引的占位符：
```
{{work.company}} | {{work.period}} | {{work.role}}
```

系统只会填充第一条记录，保持现有行为不变。

## 配置说明

### template_config.py

配置文件已更新，包含：

- `FIELD_MAPPING` - 基础字段映射（不变）
- `WORK_FIELDS` - 工作经历字段模板
- `PROJECT_FIELDS` - 项目经历字段模板
- `EDUCATION_FIELDS` - 教育经历字段模板
- `ARRAY_FIELDS` - 数组字段配置

### filler_service.py

新增方法：
- `build_replacements()` - 增强版，支持多索引占位符
- `_detect_array_row_pattern()` - 检测数组占位符
- `_has_indexed_placeholder()` - 检查是否有索引占位符
- `_populate_array_rows()` - 动态填充数组行

## 测试文件

- `tests/test_dynamic_filler.py` - 测试动态填充核心逻辑
- `tests/test_filler_multiple_rows.py` - 完整端到端测试

## 向后兼容性

✅ 完全向后兼容：
- 原有的 `{{work.company}}` 等占位符仍然正常工作
- 只会填充第一条记录，保持现有行为

## 示例

### 输入数据
```python
resume_data = ResumeData(
    work=[
        WorkItem(company="公司A", period="2020-2023", role="工程师"),
        WorkItem(company="公司B", period="2018-2020", role="实习生"),
    ],
    # ... 其他字段
)
```

### 模板配置
```
第1行: {{work0.company}} | {{work0.period}} | {{work0.role}}
第2行: {{work1.company}} | {{work1.period}} | {{work1.role}}
第3行: {{work2.company}} | {{work2.period}} | {{work2.role}}
```

### 填充结果
```
第1行: 公司A | 2020-2023 | 工程师
第2行: 公司B | 2018-2020 | 实习生
第3行: (空)
```
